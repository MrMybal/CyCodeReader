# CyCodeReader v0.1.1 — bêta publique Windows x64

Première publication publique de CyCodeReader. Deux formats sont proposés :

- **Portable** : extraire tout le ZIP dans un dossier accessible en écriture.
- **Installateur** : installation pour l'utilisateur courant, sans droits administrateur.

## Nouveautés

- Logo intégré à l'application, à l'installateur et à l'interface ; barre d'outils
  compacte et minimap activée par défaut.
- Fenêtre de recherche/remplacement dédiée, repères dans la minimap et recherche
  dans tous les documents ouverts avec Ctrl+Shift+F.
- Comparaison de fichiers et de buffers en vue côte à côte ou unifiée.
- Plugin Git : détection du dépôt, comparaisons avec HEAD et l'index, historique
  des fichiers et des sélections, aperçu des différences dans l'historique.
- Correction dans le module Diff de CyUI : les deux colonnes partagent le même
  défilement et restent alignées. Reader utilise directement ce module commun.
- Distribution portable et installable, avec un système de mise à jour prévu
  pour les futures versions stables publiques. Aucun jeton GitHub n'est embarqué.

## État de cette bêta

Les tests automatisés Windows passent pour Reader (16/16) et CyUI (8/8).
Le portable, l'installateur et les sommes SHA-256 sont générés automatiquement.
La validation interactive sur un Windows propre, l'installation/désinstallation
et une mise à jour complète entre deux versions restent à effectuer.

Windows 10/11 x64 avec OpenGL 3.3 est requis. Git doit être installé et disponible
dans PATH pour le plugin Git. Les binaires ne sont pas signés. Les fichiers sont
limités à 4 Mio et la récupération des documents après un crash n'est pas encore
implémentée. Le compagnon CyToolsCore/MCP est optionnel et nécessite son SDK séparé.

Cette release est marquée **préversion** sur GitHub. Le canal de mise à jour de
l'application recherche uniquement les versions stables ; il ignore les bêtas.
Les versions Linux/macOS et ARM64 ne font pas partie de cette distribution.
