## Local MCP access profiles

- **Free** is the default for new installations and configurations without an
  explicit profile choice. Connect to the copied `http://127.0.0.1:PORT/mcp`
  address without a token; every registered operation is allowed without an
  additional approval. The registry uses `Policy::allow_all()`.
- Preserve explicit choices. **Local controlled** keeps address-only reads under
  host policy; **Token only** requires a token and permits all registered
  operations; **Protected** requires a token and retains read/edit permissions.
- Choose the profile in **CyMCPSDK / MCP**; it is saved for the next restart.
  Settings accept `accessProfile`, with `access_profile` as an alias. Unknown or
  conflicting choices stop service startup rather than choosing another profile.
- Copy the MCP address directly. The console also accepts `--connect URL`, in
  addition to private connection descriptors. A protected address without valid
  credentials is refused; the CLI reports an authentication error.
- Keep argument validation, live revision, read-only and disk-conflict checks.
  Saving remains explicit. The assistant's **Allow document edits** setting stays
  independent of the local MCP profile and is off by default.
- Build CyMCPSDK 0.7.2 from source at `e562c731a146d599e3404718ea8414bb5b96b66d`
  (includes `34d4bca`); update Core to `b902736b0edb9a76365a47778af8a223d50e5b83`.
  CyUI stays at `6ef01cfcdb197f3a89d64618ce5ef8818c704728`, with one editor backend.

## Connect

Open **CyMCPSDK / MCP → MCP connection**, then copy the address or configuration.
With Free, no token or additional operation approval is needed. To retain
controlled token access, choose **Protected** and restart Reader, or set
`"accessProfile":"protected"` in the profile settings. Existing explicit profile
choices are respected. See [CLI, chat and MCP setup](../MCP.md).

## Limits

Ordinary documents remain limited to 4 MiB; larger UTF-8 documents use the paged
GUI profile, which is not exposed by this automation session. HTTP is loopback
request/response without SSE in this host. The direct stdio service supports SDK
change subscriptions. Remote tools require explicit configuration/allowlisting.
Native plugins remain trusted in-process code. Windows x64 is the packaged target.
Commercial provider accounts, interactive installation/update, Linux and macOS
were not validated for this update. See [validation scope](../Validation.md).
