# CyCodeReader 0.1.6

[Français](../../VERSION.fr.md) · [README](../../README.md)

11 November 2026 · **BETA** · Windows x64.

## Windows update handoff fix

- Correct the quoted installation-directory argument when its path ends in a
  backslash. The old command could absorb the SHA-256 and parent-process
  arguments, making the helper show **Invalid update arguments** before installation.
- Share Windows argument quoting between native process execution, update handoff
  and restart. Paths with spaces, Unicode and trailing separators are preserved.
- Validate the helper paths, SHA-256 format and parent ID before launching it.
- Retain all 0.1.5 code-font, zoom, palette, search and shutdown improvements.

## One manual upgrade from 0.1.4 or 0.1.5

An older installed launcher still constructs the failing command. Downloading a
newer package does not replace that launcher until installation succeeds.
Close Reader, then run the current installer manually once at the existing
installed location. Preferences are retained; uninstalling is not required.

For a portable edition, close Reader and replace its program files with the
complete corrected portable ZIP in the existing folder, preserving `data/` and
custom plugins. Use the matching edition. A helper that refuses its arguments
has not replaced application or user files.

## Validation and limits

The reported 0.1.5 download matches its published SHA-256. Twelve compiler-evaluated
checks cover the production quote helper. The actual Windows command-parser
round-trip fixture, update sources and native process adapter are checked by
MSVC /Zs only. Windows x64 public Release builds keep native tests OFF; package,
source/data and complete bilingual-manual integrity are checked locally.
No Reader, helper, installer or native test was launched. End-to-end installed
and portable update/restart acceptance and Linux/macOS remain unverified.
