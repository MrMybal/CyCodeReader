# CyCodeReader 0.1.4

[Français](../../VERSION.fr.md) · [README](../../README.md)

7 November 2026 · **BETA** · Windows x64.

## Installation and updates

- The Windows per-user installer is the primary download in both READMEs and
  the product website. The complete portable ZIP remains available alongside it.
- New installations check public GitHub Releases in the background at startup.
  An available version opens the Updates panel. Download the verified package,
  then choose **Close and install update**; normal unsaved-document prompts remain.
- Existing startup-check preferences are preserved. Enable **Updates → Check for
  updates at startup** if checks were previously disabled.
- Installed copies download Setup and portable copies download the matching ZIP.
  Reader handles the helper internally; no separate update package is required.
- Public release packaging refuses builds with online update checks disabled.

## Validation and limits

Windows x64 Release compilation, packaging policy tests and the complete CyDoc
export are checked. The installer, application and update helper were not
launched locally. Full online update handoff, clean-machine installation and
Linux/macOS graphical acceptance remain unverified. An OpenGL 3.3 driver is required.
The application remains beta and retains its documented editor/plugin limits.
