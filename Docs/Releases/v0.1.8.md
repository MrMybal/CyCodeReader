# CyCodeReader 0.1.8

[Français](../../VERSION.fr.md) · [README](../../README.md)

20 November 2026 · **BETA** · Windows x64.

## Native assistant and automation

- Replace the optional Python SDK service with source-built CyMCPSDK 0.7.1.
- Add the integrated CyMCP::ChatUI assistant beside code, with streaming replies,
  cancellation, explicit attachments, provider/model discovery and private history.
- Share one operation registry between chat, the console and external MCP clients:
  30 operations in the GUI, 22 in an independent headless text session.
- Operate on the actual live buffers, selections, cursor and Undo/Redo on the GUI
  thread. Editing is opt-in; revision, read-only, dirty-close and disk guards remain.
  Saving is explicit and Save As refuses an existing destination.
- Ship `app/cycodereader_cli.exe` with list, describe, JSON invoke, JSONL, headless
  service and MCP modes. `--connect` addresses an already running Reader instance.
  Keep the original `--serve`, `--desktop-service` and Python forwarding commands.
- Keep durable, owner-scoped job receipts across restarts, cooperative cancellation,
  quota checks before actions, temporary result chunks and explicit receipt removal.
  An expired result or interrupted response never automatically replays an action.
- Provide compact discovery, document resources/grep, invalidation/notifications,
  optional metadata metrics and adjustable API context windows.
- Optionally connect explicitly configured and allowlisted remote MCP tools.
- Pin Core `7d0a468`, CyUI `6ef01cf` and published SDK `b0eea5e` with source API 1.
  Keep the existing paged editor, JetBrains Mono, zoom, palette and update recovery.

## Getting started

Open **CyMCPSDK / MCP**, configure a tool-capable provider and model, then connect.
The assistant starts with read access; enable document edits deliberately for a new
connection. API credentials come from a named environment variable. Put persistent
connection settings in `settings.json`; fields edited in the panel apply to the session.
Local model services are supported, but Reader does not download engines or weights.

The same panel copies read/edit MCP configurations. See [the CLI/MCP guide](../MCP.md)
for commands, authenticated loopback descriptors, connection setup and legacy job import.

## Limits and validation

Ordinary documents remain limited to 4 MiB. Larger UTF-8 documents use the existing
paged GUI profile; they are not exposed by this automation session. HTTP is
authenticated loopback request/response, without SSE in this host; direct stdio
supports SDK change subscriptions. Remote tools require explicit allowlisting;
this adapter does not subscribe to remote notifications. Native plugins remain
trusted in-process code and cannot be forcibly interrupted.

Windows Release builds, native regressions, synthetic chat/CLI/MCP scenarios and
the extracted portable package were checked locally. Commercial providers,
interactive installation/update, physical desktop input, Linux and macOS remain
unverified for this migration. See [validation details](../Validation.md).
