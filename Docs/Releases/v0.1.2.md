# CyCodeReader 0.1.2

An illustrated English/French CyDoc manual is now integrated with Help, contextual
buttons and F1/Shift+F1. The same reader is bundled for offline use and published
with local search, images, diagrams, code examples and API/MCP reference.

- [Documentation](https://mrmybal.github.io/CyCodeReader/#/en/overview)
- [Documentation française](https://mrmybal.github.io/CyCodeReader/#/fr/overview)
- GitHub Actions generates and deploys the complete reader on main-branch changes.
- Windows packaging includes all help resources; public builds enable the existing
  stable-release update checks. Download and installation require user action.
- Ordinary builds exclude native test executables; test builds remain opt-in.

Windows x64 production binaries were built with native tests disabled. The desktop
application, MCP runtime and updater were not launched for this release. Native
interaction, clean-machine installation and Linux/macOS acceptance remain pending.
The manual records language-service, plugin, file-size and recovery limits.

Use the portable ZIP or the per-user Windows installer. The original application
is GPL-3.0-only; bundled dependencies retain their licences.
