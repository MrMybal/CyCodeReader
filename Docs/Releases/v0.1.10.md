# CyCodeReader 0.1.10

[Français](../../VERSION.fr.md) · [README](../../README.md)

20 November 2026 · **BETA** · Windows x64.

## Zig and ZON

- Add the common CyUI Zig and Zig Object Notation profiles, bringing the built-in
  catalogue to 104 modes. Recognize `.zig`, `build.zig`, `.zon` and `build.zig.zon`.
  Automatic detection uses the shared registry and preserves plugin precedence.
- Keep one selected language across the editor, open-document search previews,
  file/tab/saved comparisons and history diffs. Recoloring keeps source text,
  revisions, selection and Undo unchanged; diff view state is retained.
- Persist manual choices as stable text IDs, separately from Automatic. Restore
  them when saved files are reopened; preserve choices through edits and Save As.
  Unavailable plugin IDs and unrelated preferences remain saved.
- Add native file-dialog filters and Zig/ZON badges; All files remains the default.
- Project contextual lexical spans onto paged UTF-8 fragments, validating byte
  offsets and character boundaries. Reuse the existing bounded syntax cache.
- Pin CyUI `e8ccec0a96ed820fc46e86059e010efafcef687e`, which contains the shared
  Zig/ZON implementation. Core `b902736b0edb9a76365a47778af8a223d50e5b83` and
  CyMCPSDK 0.7.2 `e562c731a146d599e3404718ea8414bb5b96b66d` stay unchanged.

Use **Syntax → Automatic**, **Zig**, **ZON** or **Plain text**. See
[syntax modes and persistence](../SyntaxModes.md) and the
[bilingual sample guide](../../examples/zig/README.md).

## Limits

This is offline syntax highlighting, without ZLS, a Zig compiler, debugger or
semantic analysis. Ordinary documents remain limited to 4 MiB; larger UTF-8 files
use the paged profile. Contextual paged coloring is bounded to 32 MiB; larger
sources stay plain without a whole-file coloring read. Paged automation and
unsaved-buffer/full-session/Undo recovery remain unavailable. Manual syntax
preferences do not restore unsaved content. See [paged limits](../PagedText.md).

Windows Release compilation, source/data checks, offline documentation and
compile-only regression fixtures were verified. Native/GUI and installer execution
remain untested under the workstation's antivirus restrictions. No Linux/macOS
packages or runtime acceptance are supplied. See [validation scope](../Validation.md).
