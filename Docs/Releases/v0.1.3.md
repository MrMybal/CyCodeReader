# CyCodeReader 0.1.3

[Français](../../VERSION.fr.md) · [README](../../README.md)

Published 6 November 2026 · **BETA** · Windows x64. Development continues after
the first public beta; the public update channel is not a claim of stable maturity.

## Changes

Verse files now use the shared CyUI syntax engine. `.verse` and `.digest.verse`
are detected automatically and Verse is available in the searchable Syntax menu.
The native scanner handles keywords, built-in types, attributes, specifiers,
numbers, strings/interpolation, nested block comments and indented comments.
Syntax plugins can inherit Verse and customize its word families/associations.
Verse compilation, UEFN connectivity and language-server completion are not included.

The bundled and online CyDoc manuals now use the current reader with complete
English/French guides and public API references, nested navigation, header search
(Ctrl+K), six themes and in-window image/gallery enlargement. F1 and contextual
help use `Documentation/Documentation.html`; historical links remain compatible.
The same complete export is included in both Windows distribution formats.

- [Documentation](https://mrmybal.github.io/CyCodeReader/Documentation.html#/en/overview)
- [Documentation française](https://mrmybal.github.io/CyCodeReader/Documentation.html#/fr/overview)

## Known limitations and validation

Windows x64 Release compilation, compiler-evaluated scanner checks and documentation
checks passed. The native application, SDK/MCP companion, updater and installer
were not launched. Desktop interactions, plugin/Undo runtime scenarios,
clean-machine installation and Linux/macOS acceptance remain pending.

Extract the entire portable ZIP or use the per-user Windows installer. An OpenGL
3.3 driver is required. Public builds use the existing stable GitHub update checks;
downloading/installing still requires an explicit action. Settings and user files
retain their existing ownership. The application is GPL-3.0-only, and bundled
dependencies retain their respective licences.

Reader remains limited to 4 MiB text files and literal search with ASCII case
folding. Project services, language servers, recursive folder search, regex,
macros, crash recovery and complete session/Undo restoration are not included.
Native ABI 1 plugins run as trusted in-process code and require a restart;
there is no marketplace or native sandbox. The private CyToolsCore companion
is optional and is not bundled with the native editor.

These are documented limits, not a bug-by-bug release list. No such list is
published with these notes; consult the [issue tracker](https://github.com/MrMybal/CyCodeReader/issues)
for reported problems.
