# CyCodeReader 0.1.5

[Français](../../VERSION.fr.md) · [README](../../README.md)

11 November 2026 · **BETA** · Windows x64.

## Code readability

- JetBrains Mono Regular 2.304 is bundled under SIL OFL 1.1 for code editors,
  source previews and comparisons. Its original font bytes and licence are included.
- Ctrl + mouse wheel scales the hovered code view from 50 to 300%; split diff
  columns use one scale. Document text and Undo history are preserved.
- A palette inspired by Rider uses orange strings, green comments, blue keywords,
  mauve types and turquoise functions according to each syntax mode. TODO comment
  annotations keep the comment colour; theme contrast adjusts the shade.
- Multiline block guides remain on braces; parameter lists no longer acquire a
  vertical guide through parameter names. Minimap support remains available.

## Search and closure

- Open-document search previews highlight all occurrences with the active query,
  case and whole-word options. The code editor receives the matching display marks.
- Global marks no longer inherit a stale selection-only scope from local Find.
- Accepted closure hides the main and detached windows before worker cleanup.
  SDK/update cancellation starts immediately and the fixed two-second SDK wait
  is removed. Save/discard/cancel prompts still guard unsaved documents.

## Sources, validation and limits

The release pins published CyUI commit `6173630ad5eb1e585eee1a0e7d3617285563e774`,
which owns the shared code font, zoom, colours and guide correction. Corresponding
Reader sources are available at tag `v0.1.5`; dependency locks and notices ship
in the source tree and binary packages retain their required licences.

Windows x64 Release compilation, package integrity, source/data checks and the
complete bilingual CyDoc/showcase export are checked locally. Native regression
bodies were checked by MSVC /Zs only. No application, installer, updater or native
test was launched. Actual closure timing, wheel/DPI/font rendering, installation
and online update handoff remain unverified, as do Linux/macOS. An OpenGL 3.3
driver is required. Existing screenshots predate this font/palette update.
