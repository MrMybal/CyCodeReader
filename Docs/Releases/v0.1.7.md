## Shared native Core and large UTF-8 files

- Pin Core `f5e6261bf8acf22d0b3241622ed4294322724fb9` and CyUI
  `0ba1ba663b4b2bf46d066a32829bc91ea2743cba` with source API 1.
- Share native documents, encodings, live search, text plugins, processes,
  transport and common utilities instead of maintaining Reader copies.
- Open UTF-8 files above 4 MiB through native paged storage and asynchronous
  views. Edits, Undo/Redo, literal search, 64-bit navigation and complete streamed
  saves run on a worker. Save As preserves the original and refuses existing targets.
- Keep rejected/cancelled input available for copying and acknowledgement.
  Retain typing while a native proposal is pending, and detect a first CRLF even
  beyond a 64 KiB page boundary.
  Preserve UTF-8 BOM and untouched LF/CRLF/CR; new text follows the native newline policy.
- Supply an injectable shared graphical backend for the IDE's existing native
  owner, including authoritative commit receipts and native history contracts.
- Retain the 0.1.6 updater fix, JetBrains Mono, Ctrl+wheel, shared code colours,
  search highlighting and accepted-close window hiding.

## Profile limits

Small files keep the ordinary editor, formats, minimap, folding and multi-cursor.
Paged mode has no minimap, folding, multiple cursors, wrapping, snippets, encoding
conversion, whole-text comparisons, replace-all or selection-only search.
Contextual syntax uses a complete bounded snapshot up to 32 MiB; larger sources
show plain text with an explicit notice. Imports/indexing may take time.
Standalone paged SDK/MCP registration and durable recovery await a common native
session contract; unsaved paged work remains volatile. See [PagedText](../PagedText.md).

## Distribution and validation

Local production Release builds keep native tests OFF and public updates ON.
The per-user Windows installer, complete portable ZIP and SHA-256 sums are
provided with the public release. The numeric release is on the public update
channel; beta maturity and the validation limits below still apply.
Source/data, compiler-only fixtures, package and bilingual offline-documentation
checks are recorded in [Validation](../Validation.md).

Application/helper/CLI/installer/native tests are not executed while the existing
antivirus suspension applies. Interactive, install/update, IDE backend runtime,
Linux and macOS acceptance remain unverified. GitHub Actions stays disabled.
