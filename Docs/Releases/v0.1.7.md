## Profile limits

Small files keep the ordinary editor, formats, minimap, folding and multi-cursor.
Paged mode has no minimap, folding, multiple cursors, wrapping, snippets, encoding
conversion, whole-text comparisons, replace-all or selection-only search.
Contextual syntax uses a complete bounded snapshot up to 32 MiB; larger sources
show plain text with an explicit notice. Imports/indexing may take time.
Standalone paged SDK/MCP registration and durable recovery await a common native
session contract; unsaved paged work remains volatile. See [PagedText](../PagedText.md).

## Distribution and validation

Local production Release builds keep native tests OFF and public updates ON.
Portable ZIP, per-user installer and SHA-256 sums are prepared locally; they are
not release assets until publication. Published downloads remain version 0.1.6.
Source/data, compiler-only fixtures, package and bilingual offline-documentation
checks are recorded in [Validation](../Validation.md).

Application/helper/CLI/installer/native tests are not executed while the existing
antivirus suspension applies. Interactive, install/update, IDE backend runtime,
Linux and macOS acceptance remain unverified. GitHub Actions stays disabled.
