## SDK / MCP companion {#connection}

The native application owns documents and revisions. CyToolsCore owns jobs, identities, permissions and MCP. Follow this application’s MCP reference for companion requirements and access modes. Keep instance descriptors and credentials in their local storage; they are not documentation resources.
