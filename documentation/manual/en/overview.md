## Platforms and scope {#platforms}

Local Windows compilation is documented. Architecture, Validation and Roadmap retain the actual feature and acceptance status. Linux/macOS code or CI configuration does not establish validation on those platforms.

Help is shipped locally and opens through `file://` without a server or connection. External reference links remain optional. The CyDoc reader provides language and theme selection.
