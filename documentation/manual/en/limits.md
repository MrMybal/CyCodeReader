## Read capability claims carefully {#limits}

Original technical guides and their dates are preserved. Compilation does not prove execution of a GUI scenario, server or platform. Known gaps and remaining checks stay in Validation and specialized references.

## Languages {#translations}

User guides have English and French versions with common IDs. Original English references and API schemas are retained; the reader falls back to English where a translation is missing. The [translation report](doc:translation-report) exposes missing/outdated pages. Translation is not automatic.

## Local reader {#reader}

CyDoc’s theme selector includes light and dark themes. Initial appearance follows reader/system preferences. Minimal media controls remain available on hover, focus and touch. Escape reduces enlarged media. Reading positions and personal data depend on file-origin/browser storage behavior; no server receives them.

Source indexing is lexical and limited to selected application-owned files. It does not replace Doxygen, a compiler or Unreal macro analysis. The native Windows help URL converter does not support extended paths.
