## Shortcuts {#shortcuts}

| Shortcut | Action |
|---|---|
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as |
| Ctrl+Alt+S | Save all |
| Ctrl+Shift+F | Search open documents |
| Ctrl+P | Files / actions |
| F1 | Documentation |
| Shift+F1 | Context help |

On macOS, Cmd/Ctrl adaptation follows ImGui platform behavior; actual macOS acceptance remains pending. Filter fields and dialogs own their keyboard routing.
