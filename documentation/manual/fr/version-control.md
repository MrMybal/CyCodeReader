Le plugin Git de Reader fournit des comparaisons en lecture seule via le fournisseur de comparaison. Consultez Comparison et Plugins pour HEAD/index/disque/buffer, l’historique et les contraintes. Ces vues ne constituent pas le système complet de commits, push ou fusion de l’IDE.
