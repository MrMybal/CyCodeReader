## Raccourcis {#shortcuts}

| Shortcut | Action |
|---|---|
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as |
| Ctrl+Alt+S | Save all |
| Ctrl+Shift+F | Search open documents |
| Ctrl+P | Files / actions |
| F1 | Documentation |
| Shift+F1 | Context help |

Sur macOS, l’adaptation Cmd/Ctrl dépend des comportements ImGui de la plateforme ; la validation réelle macOS reste à faire. Les champs de filtre et les boîtes de dialogue ont leur propre routage clavier.
