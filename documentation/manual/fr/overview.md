## Plateformes et périmètre {#platforms}

La compilation Windows locale est documentée. Les fonctionnalités et validations réellement effectuées sont détaillées dans les références Architecture, Validation et Roadmap. La présence de code Linux/macOS ou d’un workflow CI ne constitue pas une validation de ces plateformes.

L’aide est fournie localement. Elle s’ouvre par `file://`, sans serveur ni connexion nécessaire. Les liens externes des références restent facultatifs. Le choix de langue et le sélecteur de thème appartiennent au lecteur CyDoc.
