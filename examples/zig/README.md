# Zig / ZON syntax samples

Open `demo.zig`, `build.zig` and `build.zig.zon` in Reader. Automatic mode uses
CyUI's file associations; select Zig, ZON or Plain text from Syntax to override
them. A manual choice is remembered for saved files and follows Save As.
These are highlighting samples, not a complete build project. They need no Zig
installation. Reader does not provide ZLS, compilation, debugging or semantics.

See [the syntax guide](../../Docs/SyntaxModes.md).

## Français

Ouvrez `demo.zig`, `build.zig` et `build.zig.zon` dans Reader. Le mode automatique

Ils ne nécessitent pas Zig. Reader ne fournit ni ZLS, ni compilation, ni
débogage, ni analyse sémantique. Voir le [guide des modes](../../Docs/SyntaxModes.md).
