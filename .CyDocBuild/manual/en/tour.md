## Interface {#interface}

Tabs hold documents; the minimap and scrollbar mark search matches. The default layout keeps the file sidebar hidden. View changes wrapping, whitespace and text size. These existing screenshots use an English interface and sample files; they illustrate editing controls, not your local documents.

## Help {#help-flow}

F1 opens the local manual; Shift+F1 opens contextual help. The reader's header search and Ctrl+K search all manual pages. Change language without losing the page. Images enlarge within the documentation window; Escape reduces them.
