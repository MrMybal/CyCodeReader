## Appearance {#appearance}

View selects English/French, a theme, text size, wrapping, whitespace and minimap. Graphite is the application's own appearance; the supplied theme choices are available in the same controls. Reset layout restores the compact default toolbar and hidden file sidebar. Preferences retain view/options choices; complete document-session/crash restoration is not supplied.

## Storage {#storage}

Portable/development settings are beside the application under `data/reader`. Installed builds use `%LOCALAPPDATA%/CyCodeReader/reader`. Close instances before moving installation files or manually inspecting preferences. Uninstall preserves per-user settings.
