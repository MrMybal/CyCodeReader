## Filters {#filters}

File, Edit, Search, Compare, Encoding, View, Syntax, Extensions and Git menus have independent search fields. Filter syntaxes by name or `.hlsl`/`.glsl`, files by name/path, and plugin/options/search-result lists by their visible content. Matching ignores Latin case/accents and accepts multiple words in English/French.

Ctrl+F focuses the current filtered panel field; the editor retains document Find. Escape clears the query. Filtering does not execute a command, save a document or commit a hidden property draft. Clear the filter when a command or option seems missing.
