## Keys {#shortcuts}

| Shortcut | Action |
| --- | --- |
| Ctrl+N / Ctrl+O | New / open files |
| Ctrl+S / Ctrl+Shift+S / Ctrl+Alt+S | Save / Save As / save all |
| Ctrl+W / Ctrl+Tab | Close / next document |
| Ctrl+F / Ctrl+H | Find / replace window |
| F3 / Shift+F3 | Next / previous match |
| Ctrl+Shift+F | Search open documents |
| Ctrl+G | Go to line |
| Ctrl+P / Ctrl+Shift+P | Open-file / action palette |
| F1 / Shift+F1 | Manual / contextual help |

Ctrl+F in a focused filtered panel targets its filter; in the editor it keeps document search. Escape clears a filter or closes its focused search window. The documentation reader has its own Ctrl+K shortcut. These bindings describe the supplied desktop commands, not full Rider/Visual Studio keymaps.
