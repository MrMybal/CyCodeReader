## First edit {#first-work}

1. Use Ctrl+O to select one or several text files, drag files onto the window or pass their paths on the command line.
2. Use Ctrl+N for an untitled draft. Choose a syntax if the draft has no useful extension.
3. Edit, then Ctrl+S saves a named document; Ctrl+Shift+S chooses Save As. Ctrl+Alt+S saves all.
4. Use Ctrl+F to find text or Ctrl+Shift+F to search every open buffer.

Reader does not require a solution or project root. A `.sln` or `.uproject` opens as text; use CyCode for project/build/language-server workflows.

## Close carefully {#close}

Ctrl+W closes the active tab. Save/Discard/Cancel prompts preserve unsaved work until you choose. Cancel keeps the document open. Open another application instance for an independent set of files. Crash recovery is not provided; save useful drafts explicitly.
