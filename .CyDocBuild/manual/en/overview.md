## Start here {#getting-started}

CyCodeReader edits code and text files without opening an IDE project. Start with [opening files](doc:quickstart#first-work), the [illustrated tour](doc:tour#interface), [editing](doc:editing#documents) or [search](doc:search#find).

## Platforms {#platforms}

Windows x64 packages include a portable edition and a per-user installer. An OpenGL 3.3 driver is required. The editor does not need Python; the optional [MCP companion](doc:mcp#connection) has separate prerequisites. Linux/macOS source builds are planned; no native packages are supplied here.
