Public operations for Automation.

These contracts describe the native service exposed by the official SDK/MCP integration. Availability depends on the configured backend, project and permissions. Consult the [common contract](doc:api-links#contract) for revisions, previews and asynchronous jobs.

## Operations {#operations}

- [`automation_status`](doc:operation-automation-status-automation-status) — Inspect SDK version, exact source identity, mode, permissions and supported optimization switches.
- [`automation_metrics`](doc:operation-automation-metrics-automation-metrics) — Read optional metadata-only duration/volume/cache metrics.
