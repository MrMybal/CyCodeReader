## Touches {#shortcuts}

| Raccourci | Action |
| --- | --- |
| Ctrl+N / Ctrl+O | Nouveau / ouvrir des fichiers |
| Ctrl+S / Ctrl+Shift+S / Ctrl+Alt+S | Enregistrer / enregistrer sous / tout enregistrer |
| Ctrl+W / Ctrl+Tab | Fermer / document suivant |
| Ctrl+F / Ctrl+H | Fenêtre de recherche / remplacement |
| F3 / Shift+F3 | Correspondance suivante / précédente |
| Ctrl+Shift+F | Recherche dans les documents ouverts |
| Ctrl+G | Atteindre une ligne |
| Ctrl+P / Ctrl+Shift+P | Palette des fichiers / des actions |
| F1 / Shift+F1 | Manuel / aide contextuelle |

Ctrl+F cible le filtre d’un panneau filtrable qui possède le focus ; dans l’éditeur il conserve la recherche du document. Échap efface un filtre ou ferme sa fenêtre de recherche active. Le lecteur documentaire possède son propre Ctrl+K. Ces touches décrivent les commandes fournies, pas des profils Rider/Visual Studio complets.
