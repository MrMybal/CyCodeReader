Opérations publiques pour Interface.

Ces contrats décrivent le service natif exposé par l’intégration SDK/MCP officielle. La disponibilité dépend du service configuré, du projet et des autorisations. Consultez le [contrat commun](doc:api-links#contract) pour les révisions, les aperçus et les tâches asynchrones.

## Opérations {#operations}

- [`ui_state`](doc:operation-ui-state-ui-state) — Consulter l’état de l’interface et les documents de cette instance.
- [`ui_activate_document`](doc:operation-ui-activate-document-ui-activate-document) — Activer un document déjà ouvert dans cette interface.
- [`ui_preferences`](doc:operation-ui-preferences-ui-preferences) — Modifier le thème, la langue ou les options de présentation prises en charge.
