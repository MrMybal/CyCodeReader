## Première modification {#first-work}

1. Utilisez Ctrl+O pour choisir un ou plusieurs textes, déposez des fichiers sur la fenêtre ou passez leurs chemins en ligne de commande.
2. Ctrl+N crée un brouillon sans fichier. Choisissez une syntaxe si le brouillon n’a pas d’extension utile.
3. Modifiez, puis Ctrl+S enregistre un document nommé ; Ctrl+Shift+S ouvre Enregistrer sous. Ctrl+Alt+S enregistre tout.
4. Ctrl+F cherche dans le document et Ctrl+Shift+F dans tous les documents ouverts.

Reader n’exige ni solution ni racine de projet. Un `.sln` ou `.uproject` s’ouvre comme texte ; utilisez CyCode pour les projets, compilations et serveurs de langage.

## Fermer avec soin {#close}

Ctrl+W ferme l’onglet actif. Les choix Enregistrer/Abandonner/Annuler préservent le travail tant que vous n’avez pas décidé. Annuler conserve le document ouvert. Une autre instance de l’application garde un ensemble de fichiers indépendant. La récupération après incident n’est pas fournie ; enregistrez explicitement les brouillons utiles.
