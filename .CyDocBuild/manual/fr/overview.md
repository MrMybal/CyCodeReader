## Commencer {#getting-started}

CyCodeReader modifie des fichiers de code et de texte sans ouvrir de projet d’IDE. Commencez par [ouvrir des fichiers](doc:quickstart#first-work), la [visite illustrée](doc:tour#interface), l’[édition](doc:editing#documents) ou la [recherche](doc:search#find).

## Plateformes {#platforms}

Les paquets Windows x64 comprennent une édition portable et un installateur par utilisateur. Un pilote OpenGL 3.3 est nécessaire. L’éditeur n’exige pas Python ; le [compagnon MCP facultatif](doc:mcp#connection) a ses propres prérequis. Les compilations source Linux/macOS sont prévues ; aucun paquet natif n’est fourni ici.
